# Contributing

Thanks for helping curate this list!

## What belongs here

- Unofficial, community-built tools for installing, debloating, tweaking, or customizing Windows.
- Projects with a public source repository (GitHub, GitLab, Codeberg, etc.) and recent maintenance.
- Free or open-source tools. Commercial tools belong elsewhere.

## What doesn't

- Official Microsoft products or services (winget, Sysinternals, Rufus-style vendors selling licenses, etc.).
- Abandoned or archived projects with a maintained alternative already listed.
- Duplicates — check the existing entries first.
- Anything primarily used for license circumvention or piracy.

## Adding an entry

1. Fork and create a branch.
2. Add your entry to the most relevant section, keeping alphabetical order where a section is already alphabetical.
3. Use the format: `- [Name](link) - One short, factual sentence ending with a period.`
4. One entry per pull request for new sections; batch related fixes are fine.
5. Open a pull request describing the tool.

## Guidelines

- Keep descriptions under ~150 characters and avoid marketing language.
- Link to the source repository, not a mirror or download aggregator.
- If a project is Windows 11 only, say so in the description.
